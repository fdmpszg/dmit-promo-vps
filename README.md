## 三大機房 + 三條線路，到底怎麼選

DMIT 的產品線有點像咖啡店的菜單——同一個機房，可能同時掛著 Pro（CN2 GIA）、Eyeball（CMIN2+AS9929）、T1（國際線路）三個版本，配置參數差不多，但價格能差出好幾倍。這裡給你一個選擇思路：

**洛杉磯 LAX**——延遲相對穩定，CN2 GIA 回程對電信用戶極友好，是大多數人買 DMIT 的第一站。適合跨境訪問、做站、API 代理、需要美國 IP 解鎖 Netflix/ChatGPT 的場景。

**香港 HKG**——延遲低、對華南用戶特別友好，CN2 GIA 版本電信延遲通常在 20-40ms。但香港機房價格整體比洛杉磯貴一截，且 Premium 系列長期缺貨。適合對延遲敏感的遊戲服務、辦公類應用、亞太分發節點。

**東京 TYO**——日本線路，CN2 GIA + CTG GIA + CMI 三網回程，對華東用戶延遲表現不錯。價格介於洛杉磯和香港之間。

如果預算有限、不在乎國內延遲，直接走 T1 國際線路，$36.9/年起，美國/香港/東京都能選。如果你最看重國內連線品質，那就挑 Pro 或 Eyeball 系列，配合上面的循環折扣優惠碼，年付下來其實不會比 T1 貴太多。

**SLA 補償階梯**——目前 SLA 保證 99%。低於 99% 補償半個月週期費用，低於 95% 補償一個月，低於 90% 補償兩個月。雖然平時基本用不上，但萬一遇到機房抽風，這個條款就是真金白银。

**Premium / Eyeball 首次保證全球可訪問**——新單首次保證 IP 全球可連，如果首次連不上（排除不可抗力），可以走免費換 IP 流程。注意 Tier 1 系列不在此保障範圍內，敏感地區首次連接建議加購 IP Guarantee+ 服務。

**退款政策**——新購 3 天內、流量未超 30GB 可全額退款（扣支付網關手續費）；新購 30 天內可部分退款，按剩餘流量或時長核算。續費不可退。退款的話記得當天就要走流程，拖過時間就沒了。
